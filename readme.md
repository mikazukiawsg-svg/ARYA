
# Project Go

## Deskripsi
Program sederhana menggunakan bahasa pemrograman Go (Golang).

## Teknologi
- Go (Golang)

## Cara Menjalankan
1. Pastikan Go sudah terinstal.
2. Buka terminal pada direktori project.
3. Jalankan perintah:

   go run main.go
